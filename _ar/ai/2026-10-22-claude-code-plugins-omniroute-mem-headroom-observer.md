## المشكلة: مساعد ذكي بذاكرة سمكة

Claude Code أداة ثورية. تكتب طلبك في الطرفية، فيقرأ الملفات ويعدل الكود ويشغل الأوامر. لكن هناك ثلاث مشاكل صامتة تفسد التجربة: **ينسى كل شيء** بمجرد إغلاق الجلسة، **يستنزف رصيدك** بسرعة عند الوصول إلى حدود الاستخدام، و**يعيد قراءة نفس السجلات والملفات** مراراً وتكراراً، مما يستهلك التوكنات بلا فائدة .

الحل ليس أداة واحدة سحرية، بل **منظومة من الأدوات** تعمل في نقاط مختلفة من دورة حياة الجلسة. أربع أدوات مفتوحة المصدر (واحدة منها رسمية من Anthropic) تعالج هذه المشاكل بدقة.

## الأداة الأولى: الحارس الذي يمنع توقف العمل (OmniRoute)

**الدور:** التوجيه الذكي بين مزودي النماذج.
**المشكلة التي يحلها:** انقطاع العمل في منتصف مهمة بسبب الوصول إلى حد الاستخدام.

OmniRoute هو بوابة ذكاء اصطناعي محلية مفتوحة المصدر، تجلس بين Claude Code وأكثر من 350 مزود نماذج. عندما ينفد رصيدك من مزود معين، ينتقل تلقائياً إلى المستوى التالي: اشتراكك المدفوع، ثم مفاتيح API، ثم النماذج الرخيصة، ثم المجانية .

**ملاحظة مهمة:** OmniRoute ليس إضافة (plugin) بالمعنى التقليدي، بل هو **برنامج مستقل** يعمل على جهازك، ويتم توجيه Claude Code إليه عبر تغيير عنوان الاتصال . كما أنه يضغط ما يرسله، مما يقلل استهلاك التوكنات بنسبة تتراوح بين 15% و95% حسب عبء العمل .

**التثبيت (جميع المنصات):**
```bash
npm i -g omniroute
omniroute run claude --model auto
```
يعمل على لينكس، ويندوز (عبر Node.js)، وماك. لا يوجد دعم رسمي لـ BSD، لكن يمكن تشغيله عبر Node.js إذا توفر.

## الأداة الثانية: الذاكرة التي لا تنسى (Claude-Mem)

**الدور:** الذاكرة الدائمة عبر الجلسات.
**المشكلة التي يحلها:** إعادة شرح نفس المشروع كل صباح.

Claude-Mem يلتقط ما يحدث في الجلسة (القرارات، إصلاحات الأخطاء، الميزات الجديدة)، يضغطها ويخزنها في قاعدة بيانات محلية (SQLite + Vector)، ثم يعيد حقن الأجزاء ذات الصلة في الجلسة التالية. يوفر ثلاث أدوات بحث: `search` و `timeline` و `get_observations`، مما يتيح للنموذج استرجاع ما يحتاجه فقط بدلاً من إعادة قراءة كل شيء .

**التثبيت (جميع المنصات):**
```bash
npx claude-mem install
```
أو من داخل Claude Code:
```
/plugin marketplace add thedotmack/claude-mem
/plugin install claude-mem
```
يعمل على لينكس، ويندوز، وماك. لا توجد متطلبات خاصة لـ BSD.

## الأداة الثالثة: المقص الذي يقطع الفوضى (Headroom)

**الدور:** ضغط السياق قبل وصوله إلى النموذج.
**المشكلة التي يحلها:** السجلات الضخمة وملفات JSON التي تلتهم نافذة السياق.

Headroom هو طبقة ضغط محلية تجلس بين الوكيل والنموذج. يوجه كل نوع محتوى إلى ضاغط مخصص: واحد لـ JSON، وآخر يفهم بنية الكود (AST-aware)، وثالث مدرب على آثار الوكلاء. النتائج: تقليل استهلاك التوكنات بنسبة 60-95% في الأعمال المعتمدة على JSON، و15-20% في جلسات البرمجة العامة، مع الحفاظ على الدقة. الضغط قابل للعكس، فيمكن للنموذج طلب النص الأصلي إذا احتاجه .

**التثبيت (جميع المنصات):**
```bash
pip install "headroom-ai[all]"
headroom wrap claude
```
يتطلب Python. يعمل على لينكس، ويندوز، وماك. لا يوجد دعم رسمي لـ BSD، لكن Python متوفر على FreeBSD.

## الأداة الرابعة: المراقب الذي يتعلم من أخطائك (Task Observer)

**الدور:** تحويل أنماط العمل المتكررة إلى مهارات قابلة لإعادة الاستخدام.
**المشكلة التي يحلها:** تكرار نفس التصحيحات والأوامر في كل جلسة.

Task Observer هو "مهارة" (skill) وليس إضافة بالمعنى التقليدي. يراقب كيف تصحح أخطاء النموذج، وكيف تعطي تعليمات أفضل، ثم يقترح تحديثات للمهارات الموجودة لديك، أو إنشاء مهارات جديدة تلائم أسلوبك. الهدف هو أن يصبح النموذج تدريجياً أقرب إلى فهمك الخاص، دون أن تضطر إلى إعادة تلقينه .

**التثبيت (جميع المنصات):**
يتم نسخ حزمة `SKILL.md` إلى مجلد المهارات:
```bash
# لينكس / ماك / BSD
mkdir -p ~/.claude/skills/task-observer
# نسخ محتوى الحزمة إلى هذا المجلد

# ويندوز
New-Item -ItemType Directory -Force -Path "$HOME\.claude\skills\task-observer"
# نسخ المحتوى
```
يعمل على أي نظام يشغل Claude Code.

## طريقة الإعداد على مختلف المنصات

### لينكس
Claude Code يعمل بشكل أصلي. تأكد من وجود Node.js 18+ (يفضل عبر nvm) و Git. الأوامر المذكورة أعلاه تعمل مباشرة. لـ OmniRoute، Node.js كافٍ. لـ Headroom، Python 3.8+.

### ويندوز
Claude Code يعمل أصلياً الآن (وليس فقط عبر WSL). ثبته عبر PowerShell:
```powershell
irm https://claude.ai/install.ps1 | iex
```
أو عبر WinGet:
```powershell
winget install Anthropic.ClaudeCode
```
تأكد من وجود Git for Windows. الأوامر الأخرى (`npx claude-mem`، `pip install headroom-ai`) تعمل في PowerShell أو CMD.

### ماك
التثبيت عبر Homebrew أو سكريبت curl:
```bash
brew install --cask claude-code
# أو
curl -fsSL https://claude.ai/install.sh | bash
```
باقي الأدوات تعمل بنفس أوامر لينكس.

### بي إس دي (FreeBSD / OpenBSD / NetBSD)
Claude Code ليس لديه دعم رسمي لـ BSD. يمكن محاولة تثبيته عبر npm إذا توفر Node.js، لكنه غير مضمون. OmniRoute (Node.js) و Headroom (Python) قد يعملان إذا توفرت المتطلبات. الذاكرة (Claude-Mem) تعتمد على Node.js و SQLite، وقد تعمل. **الخلاصة:** BSD ليس هدفاً رسمياً لهذه الأدوات، لكن الأجزاء المكتوبة بـ Node.js/Python قد تعمل.

## تسلسل التركيب الموصى به

لا تثبت كل شيء دفعة واحدة. ابدأ بالأساس:

1. **Claude-Mem أولاً:** يعالج أكبر مشكلة (النسيان) فوراً.
2. **Headroom ثانياً:** إذا لاحظت أن جلساتك الطويلة تستهلك توكنات كثيرة.
3. **Task Observer ثالثاً:** بعد أن تعتاد على سير العمل، لتحسين المهارات.
4. **OmniRoute رابعاً:** فقط إذا كنت تصطدم بحدود الاستخدام باستمرار. وتذكر أن "التوكنات اللانهائية" خرافة؛ إنه توجيه بين مزودين، وله تكاليفه وشروطه .

## خلاصة

مساعدك البرمجي قوي، لكنه بحاجة إلى ذاكرة، ومقص، وموجه، ومراقب. هذه الأدوات الأربع تحول Claude Code من "أداة تستخدمها مرة واحدة" إلى "شريك يفهم مشروعك وأسلوبك". لا تثبتها كلها في يوم واحد. ابدأ بالذاكرة، ثم أضف الضغط، ثم المراقبة، وأخيراً التوجيه إذا احتجت.
