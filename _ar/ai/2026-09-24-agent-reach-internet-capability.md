## مشكلة الوكيل الذي لا يستطيع رؤية الإنترنت

وكلاء الذكاء الاصطناعي مثل Claude Code و OpenClaw و Cursor أصبحوا أدوات قوية للغاية في البرمجة وإدارة المشاريع. لكن عندما تطلب منهم البحث عن معلومات على الإنترنت، يواجهون عائقاً كبيراً. كل منصة لها متطلباتها الخاصة: Twitter API مدفوع، Reddit يحجب عناوين IP للخوادم، Bilibili يحظر أدوات التحميل العامة، Xiaohongshu يتطلب تسجيل الدخول، والمزيد. إعداد كل منصة على حدة يستغرق وقتاً طويلاً من تثبيت الأدوات وضبط الإعدادات.

Agent Reach جاء لحل هذه المشكلة بأمر واحد.

🔗 **المستودع الرسمي:** [github.com/Panniantong/Agent-Reach](https://github.com/Panniantong/Agent-Reach)

## ما هو Agent Reach؟

Agent Reach هو **أداة مفتوحة المصدر (رخصة MIT)** تمنح وكلاء الذكاء الاصطناعي القدرة على قراءة والبحث في الإنترنت بالكامل. الفكرة الأساسية: بدلاً من أن يقوم المستخدم بإعداد كل منصة على حدة، يقوم Agent Reach باختيار وتثبيت واختبار أفضل الأدوات المتاحة لكل منصة، ثم يوفر لواجهة موحدة يستخدمها الوكيل.

المشروع يُعرّف نفسه كـ "**سقالة (scaffolding)** وليس إطار عمل (framework)". بمعنى أنه لا يعيد تغليف المحتوى، بل يختار أفضل الأدوات الموجودة (مثل `yt-dlp` لـ YouTube، `gh` لـ GitHub، `Jina Reader` لقراءة صفحات الويب) ويضعها في مكان واحد يمكن للوكيل الوصول إليه.

## كيف يعمل؟

التثبيت يتم بأمر واحد بسيط. تنسخ هذه الجملة وترسلها لوكيل الذكاء الاصطناعي الخاص بك:

```
帮我安装 Agent Reach：https://raw.githubusercontent.com/Panniantong/agent-reach/main/docs/install.md
```

بعد ذلك، يقوم الوكيل تلقائياً بـ:

1.  تثبيت أداة سطر الأوامر `agent-reach` عبر `pip`.
2.  تثبيت التبعيات النظامية مثل Node.js و `gh` CLI و `mcporter`.
3.  تكوين محرك البحث عبر MCP (Exa) مجاناً دون الحاجة إلى مفتاح API.
4.  اكتشاف البيئة (جهاز محلي أو خادم) وتقديم توصيات مناسبة.
5.  تسجيل ملف `SKILL.md` في مجلد مهارات الوكيل، بحيث يعرف الوكيل تلقائياً كيف يستخدم هذه الأدوات عند الحاجة.

بعد التثبيت، يمكنك تشغيل الأمر `agent-reach doctor` للتحقق من حالة كل قناة ومعرفة ما إذا كانت تعمل أم لا.

## المنصات المدعومة

يدعم Agent Reach أكثر من 10 منصات، مقسمة إلى فئات حسب مدى سهولة الإعداد:

### جاهزة للاستخدام (بدون إعداد)

| المنصة | الوظيفة |
|--------|---------|
| **الويب** | قراءة أي صفحة ويب (عبر Jina Reader) |
| **YouTube** | استخراج الترجمات والبحث عن الفيديو |
| **GitHub** | قراءة المستودعات العامة والبحث |
| **RSS** | قراءة أي تغذية RSS/Atom |
| **البحث الشامل** | بحث دلالي عبر Exa (مجاني، بدون مفتاح) |
| **V2EX** | المنشورات الشائعة، تفاصيل المنشور والردود |

### تتطلب إعداداً (بسيطاً)

| المنصة | ما تحتاجه |
|--------|-----------|
| **Twitter/X** | تصريح عبر Cookie |
| **Reddit** | Cookie (واجهة匿名 محجوبة) |
| **Bilibili** | تثبيت OpenCLI للترجمات |
| **Xiaohongshu** | تثبيت OpenCLI لاستخدام حالة تسجيل الدخول في المتصفح |
| **LinkedIn** | خدمة MCP للتفاصيل والبحث |

### منصات إضافية
يدعم المشروع أيضاً **Boss 直聘** (منصة توظيف صينية)، **Douyin** (تيك توك الصيني)، **WeChat Official Accounts**، **Weibo**، **Xueqiu** (منصة أسهم)، و **Xiaoyuzhou Podcast** (تحويل البودكاست إلى نص).

## الميزات الرئيسية

### مجاني بالكامل
جميع الأدوات المستخدمة مفتوحة المصدر، وجميع APIs مجانية. التكلفة الوحيدة المحتملة هي خادم وكيل (بروكسي) بقيمة 1 دولار شهرياً، وهو غير مطلوب على الأجهزة المحلية.

### الخصوصية والأمان
ملفات تعريف الارتباط (Cookies) تبقى محلية على جهازك، ولا يتم رفعها إلى أي خادم خارجي. الكود مفتوح بالكامل ويمكن مراجعته.

### التبديل التلقائي بين الأدوات
لكل منصة مسار أساسي ومسار احتياطي. إذا فشل المسار الأساسي، ينتقل Agent Reach تلقائياً إلى المسار البديل دون أي تدخل من المستخدم. مثال: عندما حظر Bilibili أداة `yt-dlp` في يونيو 2026، قام الفريق بالتبديل إلى `bili-cli` تلقائياً، ولم يلاحظ المستخدمون أي تغيير.

### متوافق مع جميع الوكلاء
يعمل مع Claude Code و OpenClaw و Cursor و Windsurf وأي وكيل يستطيع تشغيل أوامر سطر الأوامر.

### تشخيص مدمج
الأمر `agent-reach doctor` يخبرك بحالة كل قناة: ما الذي يعمل، ما الذي لا يعمل، وما هي طريقة الإصلاح.

## لمن هذا المشروع؟

Agent Reach مفيد بشكل خاص لـ:

- **المطورين** الذين يريدون من وكيلهم البحث عن حلول في GitHub و Reddit و Stack Overflow.
- **صناع المحتوى** الذين يريدون تحليل المنافسين على YouTube و Twitter و Bilibili.
- **الباحثين** الذين يحتاجون إلى جمع معلومات من مصادر متعددة بسرعة.
- **مهندسي الاختبار** الذين يبحثون عن تقارير عن مشاكل مشابهة في المنتديات و تتبع الإصدارات.

## الخلاصة

Agent Reach ليس مجرد أداة أخرى. إنه حل لمشكلة حقيقية يواجهها كل من يستخدم وكلاء الذكاء الاصطناعي: الوكيل قوي في البرمجة، لكنه أعمى عن الإنترنت. بأمر واحد، يفتح Agent Reach عيون الوكيل على منصات متعددة، مجاناً، مع الحفاظ على الخصوصية والمرونة.
