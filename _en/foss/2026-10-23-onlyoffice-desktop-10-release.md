## A Bold Decision: Make AI Optional

In an era where companies are racing to integrate AI into every corner of their software, ONLYOFFICE took the opposite decision. In version 10.0 of its desktop editors, AI is no longer a built-in component running in the background without the user's knowledge. It has become a **separate module** that needs to be downloaded and installed manually.

This decision reflects respect for user privacy and choice. If you want an AI-free editing experience, you get it by default, with no complex settings or annoying notifications. If you want to benefit from the tools, you install them with one click.

🔗 **Download Page:** [onlyoffice.com/desktop](https://www.onlyoffice.com/desktop)

## What's New in Version 10.0?

### The New AI Module

Instead of the previously separate tools (the AI agent and the AI plugin), version 10.0 combines everything into a single module that includes:

- **AI Chat:** A conversation with a smart assistant (ChatGPT, Claude, Mistral, Google Gemini, Groq, xAI, DeepSeek, or local models via Ollama, LM Studio, and GPT4ALL) directly from the start window, without opening the editor. You can attach a file (document, spreadsheet, presentation, PDF) and request summarization, proofreading, translation, or analysis.
- **AI Tools:** Ready-made tools for common tasks: reviewing documents, comparing them, converting DOCX into fillable forms, data analysis, creating pivot tables, generating presentation slides, merging and splitting PDFs, removing personal information, and more.
- **Advanced settings:** Quick AI Actions for changing text tone or rewriting it for a specific audience, Assistants that respond to changes while editing, and Saved Prompts for repeated tasks.

**Installation and Removal:** From the sidebar in the start window, choose AI Chat or AI Tools, then click "Accept & Install." To remove the module, go to Settings and click "Uninstall."

### Redesigned Start Window

The start window has been updated with a new minimalist design. The left sidebar has been redesigned, and the Templates section has been improved. The Cloud section now lists all available cloud providers as a list, with a "Connect" button to add your account.

### Odoo as a New Cloud Provider

After previous promises, **Odoo** is now available as a cloud provider in ONLYOFFICE Desktop Editors 10.0. You can add your Odoo account and edit its documents, spreadsheets, presentations, and PDFs using local fonts, print services, and spellcheckers.

### PDF Improvements

The PDF editor received major improvements:
- **Removing metadata** using the Redact tool, helping to protect sensitive information.
- **Reusable signatures** in forms.
- **AI works inside the PDF editor:** You can ask questions about the document, get summaries, and redact sensitive information.

### Platform Improvements

- **Linux:** Reduced window frame thickness and added a window shadow. This makes it easier to work on multiple documents at once and compare them side by side.
- **macOS:** Added context menus for file tabs. Right-clicking a document tab allows you to close, move, pin, or unpin the document, as well as create a new one.

### Additional Improvements

- Horizontal line settings for precise formatting.
- AutoComplete toggle for cell values.
- Sheet background support in spreadsheets.
- New display modes and extended print settings in presentations.
- Exporting slides as GIF or video.

## Download and Installation

Version 10.0 is available for **Windows, Linux, and macOS** from the official website. Updated **Snap, Flatpak, and AppImage** packages will be available later.

On Linux, you can download it as an AppImage (works on any distribution), or as a DEB/RPM package. On Windows, an MSI installer. On macOS, a DMG file.

## Summary

ONLYOFFICE Desktop Editors 10.0 is not just an update to an office suite. It is a **statement** that AI should be a tool in the user's hands, not something imposed on them. With an elegant start window, Odoo support, PDF improvements, and platform enhancements, the release offers a mature and integrated office experience. If you want an open source office suite that is Office-compatible, supports PDF, and leaves you free to choose AI, ONLYOFFICE 10.0 is worth trying.
