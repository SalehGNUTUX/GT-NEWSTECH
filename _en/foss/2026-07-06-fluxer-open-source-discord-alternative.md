## The Search for an Open Source Discord Alternative

For years, Discord has been the default platform for communication among friends, communities, and work teams. However, over time, concerns have emerged. The application is not open source, data is stored on third-party servers, and privacy policies change without notice. Many users and communities have started looking for alternatives that give them control over their data and privacy.

Fluxer is one of the most prominent of these alternatives, offering an experience similar to Discord with a focus on transparency and control.

## What Is Fluxer?

Fluxer is an open source (AGPLv3 licensed) instant messaging and VoIP application, offering messaging and voice and video calls. It is designed to be an open source, user-focused alternative for individuals and communities. The application is available on Windows, macOS, and the web, with Android and iOS applications in development.

## Key Features

### Messaging and Communities

Fluxer supports private messages, group chats, and channels for organizing communities. Messages support **full Markdown**, allowing text formatting, embedding links, images, and code blocks. Files can be shared with link previews.

### Voice and Video Calls

The application includes high-quality voice and video calls with advanced features: screen sharing, noise cancellation, echo cancellation, and microphone and camera controls. Calls are routed through the nearest server from 16 data centers distributed worldwide, ensuring good call quality.

### Community Management Tools

Fluxer provides powerful community management tools: fine-grained roles with custom permissions, transparent audit logs, and moderation tools such as banning and reporting.

### Search and Navigation

Users can search through the entire message history, with filtering options by user or date. A quick switcher menu allows fast navigation between channels and communities.

### Customization

Fluxer allows extensive customization: uploading custom emoji, saving media such as images, videos, and audio, and applying custom CSS themes to change the application's appearance. It also includes a compact mode for dense information display.

### Self-Hosting

A key feature of Fluxer is the ability to **host your own server**. You can run the Fluxer backend server on your own hardware and connect to it using official Fluxer applications, maintaining full data control. This makes Fluxer suitable for organizations and communities requiring high privacy.

## Compatibility and Download

Fluxer can be downloaded on several platforms:

**Windows (Windows 10+):** Standard installer and a special game capture version.

**macOS (macOS 10.15+):** DMG package.

**Web:** The application can be used directly from the browser and can be installed as a PWA on phones and tablets.

**Android:** An APK file can be downloaded directly from the GitHub repository (beta version).

**iOS:** Currently in a closed TestFlight beta, available only to Plutonium subscribers. A public release is expected soon.

## Arabic Language and Community

Fluxer supports **34 languages**, including Arabic, making it an attractive choice for Arabic communities. The development team encourages contribution to translation via email at i18n@fluxer.app, using AI techniques to speed up the translation process with limited human review.
